# N6 — `.env.example` block and `package.json` lines (orchestrator merges)

## `.env.example`

Insert directly after the `SUBSTRATE_LEDGER_TTL=` line (end of the uplift-2 R5 ledger block), before the TimescaleDB section.

```
# ── Ledger: anchor coverage and the verified archive (uplift-3 N6) ────────────
# `substrate ledger coverage` exits 2 when more closed hours (≥ 1 h old, last
# 7 days) hold ingest records and no anchor than this; /healthz.jobs.ledger
# reports the count either way. 0..100000. See docs/greptime-ledger.md,
# "Coverage and archive".
SUBSTRATE_LEDGER_MAX_UNCOVERED_HOURS=2
# Where `substrate ledger archive` writes when --out is omitted, and what
# infra/vps/substrate-ledger-archive.service expands into its ExecStart: an
# off-box mount, never the root disk and never the release tree — the command
# refuses /, the checkout, /opt/agent-substrate and any filesystem with fewer
# than SUBSTRATE_DEPLOY_MIN_FREE_GB gigabytes free. Unset by default: the
# command refuses by name and writes nothing. Setting SUBSTRATE_LEDGER_TTL is
# allowed only once every day that would expire has a verified manifest here.
SUBSTRATE_LEDGER_ARCHIVE_DIR=
```

| Name | Default | Read by |
| --- | --- | --- |
| `SUBSTRATE_LEDGER_MAX_UNCOVERED_HOURS` | `2` (0..100000, clamped; unparseable → default) | `config.ts` `loadLedgerSettings` → `ledger-run.ts coverage` |
| `SUBSTRATE_LEDGER_ARCHIVE_DIR` | unset → `archive` needs `--out` | `config.ts` `loadLedgerSettings` → `ledger-run.ts archive`; the unit's `ExecStart` |
| `SUBSTRATE_DEPLOY_MIN_FREE_GB` (existing, uplift-2 R7) | `5`; `0` disables | now also `ledger-run.ts archive` for the floor on `--out`'s filesystem, same `^[0-9]{1,4}$` grammar as `deploy-release.sh` |

## `package.json` scripts

Optional conveniences; `bun run substrate ledger …` already works through the existing `substrate` script. If added, after `"substrate"`:

```
    "ledger:coverage": "bun packages/cli/src/index.ts ledger coverage",
    "ledger:verify-archive": "bun packages/cli/src/index.ts ledger verify-archive",
```

No dependency changes. `zod` (already a dependency of `@substrate/mcp-server`) parses the archive files in `ledger-archive.ts`.
