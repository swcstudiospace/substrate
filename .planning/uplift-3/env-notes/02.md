# N2 env notes (orchestrator applies)

## `.env.example` block

Place after the `SUBSTRATE_SLO_*` threshold lines (next to `SUBSTRATE_SLO_PLANE_AVAILABILITY`).

```sh
# ── SLO history, capacity runway and notifications (uplift-3 N2) ────────────
# The SLO checkpoint keeps brief.p95, the plane windows, the burn ledger and the
# capacity ring across restarts. Unset, it lives at
# /var/lib/substrate/slo-checkpoint.json when that directory exists (the unit's
# StateDirectory) and is off on a bare local run; an absolute path overrides,
# `off` disables. Written every SUBSTRATE_SLO_CHECKPOINT_S seconds (60) and on
# shutdown; 0 writes only at shutdown. /slo.history reports the epoch and since.
SUBSTRATE_SLO_CHECKPOINT=
SUBSTRATE_SLO_CHECKPOINT_S=
# The index volume's size in bytes. /slo.capacity[0] (capacity.index.runway_days)
# is insufficient-data until this is set and /healthz has been read for 24 h.
# SUBSTRATE_SLO_RUNWAY_DAYS is the floor (14).
SUBSTRATE_INDEX_VOLUME_BYTES=
SUBSTRATE_SLO_RUNWAY_DAYS=
# SUBSTRATE_SLO_NOTIFY=1 schedules the transition notifier: every
# SUBSTRATE_SLO_NOTIFY_S (60) it judges the catalogue, planes, burn, capacity
# and breakers, and a breach / open breaker / recovery that holds for
# SUBSTRATE_SLO_NOTIFY_SUSTAIN_S (300) is one event on the ledger (surface
# substrate, payload.runtime slo), deduped through the checkpoint. Optional
# SUBSTRATE_SLO_WEBHOOK_URL is POSTed the same payload once per transition
# (5 s, no retry); it may carry a token, so it is a credential: never printed.
SUBSTRATE_SLO_NOTIFY=
SUBSTRATE_SLO_NOTIFY_S=
SUBSTRATE_SLO_NOTIFY_SUSTAIN_S=
SUBSTRATE_SLO_WEBHOOK_URL=
```

## `package.json` scripts

None.

## Unit

Nothing to install. `substrate-mcp.service` already has `StateDirectory=substrate` (the audit chain and the skills state live there), which is what makes the unset default resolve to `/var/lib/substrate/slo-checkpoint.json` on the host. Set `SUBSTRATE_INDEX_VOLUME_BYTES` in `/etc/substrate/substrate.env` to the Railway volume size for the runway row to be judged; `SUBSTRATE_SLO_NOTIFY=1` is an operator opt-in there too.
