# N3 — `.env.example` additions (orchestrator merges)

New block, after the `# ── Hot cache: DragonflyDB` block (after `SUBSTRATE_CACHE_CONNECT_TIMEOUT_MS=250`):

```sh
# ── Admission budgets (uplift-3 N3) ───────────────────────────────────────────
# One token bucket per authenticated surface and class (read, write,
# coordination) in the cache plane, stepped by one atomic EVAL after the bearer
# is resolved and before any handler or audit. The identity is the token's
# surface, never a body-claimed one; untokened bridge callers share `anonymous`.
# MCP batches cost one token per tools/call member and are refused whole.
# A cache that cannot answer (off, breaker open, cooldown, timeout) admits the
# caller and counts a `bypass`. Modes: `off` skips the eval (today's
# behaviour); `shadow` decides and counts substrate.admission.decisions but
# never refuses; `enforce` answers 429 with an integer Retry-After and
# {"error":"budget","class":…,"retry_after_s":…}. Anything else is shadow.
# See docs/data-planes.md, docs/observability.md and docs/grok-bot.md.
SUBSTRATE_BUDGETS=shadow
# Per surface and second; the burst is the most a bucket holds (one second of
# headroom over the rate by default). Rates may be fractional; bursts are
# positive integers; anything else keeps the default. Coordination
# (graph_claim/heartbeat/release/complete, coord_reap_leases) has its own
# bucket so a storm of reads never costs a lease.
SUBSTRATE_BUDGET_READ_RPS=20
SUBSTRATE_BUDGET_READ_BURST=40
SUBSTRATE_BUDGET_WRITE_RPS=10
SUBSTRATE_BUDGET_WRITE_BURST=20
SUBSTRATE_BUDGET_COORDINATION_RPS=30
SUBSTRATE_BUDGET_COORDINATION_BURST=60
# The bucket every accepted untokened caller shares, per class.
SUBSTRATE_BUDGET_ANONYMOUS_RPS=2
SUBSTRATE_BUDGET_ANONYMOUS_BURST=4
# Per-surface overrides, optional: SUBSTRATE_BUDGET_<SURFACE>_<CLASS>_RPS and
# _BURST with the SUBSTRATE_TOKEN_* spelling of the surface (GROK_BOT,
# SWARM_A01_ORCH, …). A half left unset is the class value above, e.g.
# SUBSTRATE_BUDGET_GROK_BOT_READ_RPS=5 keeps the read burst of 40.
```
