# N4 — `.env.example` additions (orchestrator merges)

No `package.json` script lines. One new variable.

Insert into the `# ── Memory governance` block (after the reviewer-token lines, before any `SUBSTRATE_MEMORY_GRANTS` line), or as its own block directly after `# ── Index retention sweep`:

```sh
# ── Memory lifetime (uplift-3 N4; docs/memory-governance.md § Lifetime) ───────
# What the index's serving reads do with an entry past its ttl (30d: created +
# 30 days; graph: its graph is finished or no longer indexed; permanent: never).
# report (the default) serves it tagged `expired: true`, counts it in
# substrate.memory.expired{mode=served}, and the sweep's two entries-ttl-*
# classes only count. enforce leaves it out of the brief and memory_search
# (operators may pass include_expired), counts mode=hidden, and lets the sweep
# delete it — still only under SUBSTRATE_INDEX_SWEEP=apply plus --apply. The
# retain forward refuses an expired entry in both modes. Anything else is
# report, with a boot warning. Read by the server and by the sweep job: set it
# in both environments, or the sweep keeps counting while the reads hide.
SUBSTRATE_MEMORY_EXPIRY=report
```
