# N7 — env and script lines for the orchestrator

## `.env.example`

Nothing to add: N7 reads no new variable. The smoke reads existing client-side
names only (`SUBSTRATE_URL`, `SUBSTRATE_TOKEN_GROK_BOT`, `SUBSTRATE_TOKENS_DIR`,
`SUBSTRATE_TOKEN`) plus the optional `SUBSTRATE_SMOKE_REPO` (the repo the brief is
read for; default `swcstudiospace/agent-substrate`), which is a script knob, not a
server setting. If a line is wanted beside the other smoke notes:

```
# Repo the Grok connector smoke (bun run smoke:grok) reads the brief for. The
# smoke is read-only and opt-in; it never writes, emits or retains.
SUBSTRATE_SMOKE_REPO=swcstudiospace/agent-substrate
```

## `package.json` scripts

Add beside `smoke:chaos`:

```
"smoke:grok": "bun scripts/grok-connector-smoke.ts",
```

Usage: `bun run smoke:grok` (human lines, exit 0 ok / 1 degraded / 2 failed or
usage), `bun run smoke:grok -- --json`. Needs a grok-bot bearer: the first entry
of `SUBSTRATE_TOKEN_GROK_BOT`, else the `grok-bot` file in the tokens dir named by
`SUBSTRATE_TOKENS_DIR`, else `SUBSTRATE_TOKEN`.

## Nothing else

No new surface, kind, event producer, audit policy entry (no new write route or
tool), or systemd change. `GET /slo` gains the `surfaces` sibling array and
`/metrics` the `substrate.brief.result` counter; both are additive.
