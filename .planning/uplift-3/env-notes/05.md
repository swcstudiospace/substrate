# N5 — env and script lines for the orchestrator

## `.env.example`

Append after `SUBSTRATE_DOCS_TOP_K=1024` (the docs block):

```
# One shared deadline for every dataset's retrieval in one docs_search, ms
# (uplift-3 N5). The datasets are retrieved concurrently; a dataset that misses
# it is listed in the reply's degraded_datasets while the others still answer,
# and such a partial reply is never cached. 0 keeps only the plane client's own
# 4 s per-call timeout — the pre-N5 behaviour and the rollback.
SUBSTRATE_DOCS_SEARCH_BUDGET_MS=4000
```

Append after `SUBSTRATE_SLO_PLANE_AVAILABILITY=0.99` (the SLO block):

```
# Ceiling for the docs.search.p95 row GET /slo carries beside the catalogue
# (uplift-3 N5): p95 of substrate.docs.duration, end to end, cache hit or loaded.
# Must be one of that histogram's own edges (25, 50, 100, 200, 400, 800, 1000,
# 2000, 4000, 8000 ms) or the row reports unmeasurable. Judged only after
# SUBSTRATE_SLO_MIN_SAMPLES searches; never folded into breached.
SUBSTRATE_SLO_DOCS_SEARCH_P95_MS=2000
```

## `package.json` scripts

Add beside `smoke:chaos`:

```
"docs:golden": "bun scripts/docs-golden.ts",
```

Usage: `bun run docs:golden` (offline, asserts), `bun run docs:golden -- --live`
(needs `SUBSTRATE_URL` + `SUBSTRATE_TOKEN`; prints), `bun run docs:golden -- --manifest`.
