# N1 env notes (orchestrator applies)

## `.env.example` block

Place next to the "Index retention sweep" block (the other timer-driven host job).

```sh
# ── Runtime doctor (scripts/doctor-runtime.ts; substrate-doctor.timer) ───────
# Read-only comparison of the host (systemd, redis, df, /proc, the shared env
# by key NAME) with the policy declared under infra/vps. Exit 2 on drift.
# SUBSTRATE_DOCTOR_EMIT=1 lets `--emit` post one `warning` per drift class to
# SUBSTRATE_URL/events as the substrate surface; unset, --emit only prints a
# hint. Set it on the doctor unit's drop-in, not here: the server never needs
# it. The dedupe record (last emitted drift set per class) lives at
# SUBSTRATE_DOCTOR_STATE; the unit sets it under /var/lib/substrate.
# SUBSTRATE_DOCTOR_SWAP_PAGES_PER_S is the paging rate above which the swap
# row is drift (default 0: any page moving in the one-second sample).
SUBSTRATE_DOCTOR_EMIT=
SUBSTRATE_DOCTOR_STATE=
SUBSTRATE_DOCTOR_SWAP_PAGES_PER_S=
```

`SUBSTRATE_DEPLOY_MIN_FREE_GB` is read as `deploy-release.sh` reads it (default 5, `0` disables); it already exists.
