# 07 — N7: Grok connector contract: smoke, MCP brief metadata, per-surface SLO

**Problem** (CONTEXT.md Grok row, PROPOSAL.md §N7): MCP `memory_brief` returned text only, so a connector calling the tool could not see the ETag or whether the brief was degraded; there was no per-surface brief verdict (the global `brief.p95` blends every caller); A-7 #5's connector smoke did not exist; `grok-bot` briefs read 0 in the measured process.

## What / where

1. **One matcher, one answer path** — `packages/mcp-server/src/service.ts`: `etagMatches` moved here from `server.ts` beside `briefEtag` (the server imports `mcp.ts`, so `mcp.ts` importing the matcher from `server.ts` would be a cycle); new `briefConditional(request, ifNoneMatch) → { detail, notModified }` composes the brief, matches the validator and records `observer.briefResult` once, with `surface` bounded to `SURFACES` (`unknown` otherwise — `POST /brief` takes the body's surface unchecked). `POST /brief` now calls it; the 200/304 wire shape is unchanged.
2. **MCP metadata** — `packages/mcp-server/src/mcp.ts`: `memory_brief` keeps its text byte-for-byte; `structuredContent` (with an advertised `outputSchema`) carries `etag`, `state`, `surface` (the composed-for surface — the bearer's own when the argument is omitted, so the smoke can refuse a wrong token), `failed_sources`, `snapshot_at`. New optional input `if_none_match` → `structuredContent { not_modified: true, etag, state, surface }` with the one-line text `brief unchanged (etag W/"…")` (59 chars). Description updated. `agent-card.ts` lists teachables only, not tool outputs — unchanged.
3. **Counter** — `packages/observability/src/instruments.ts`: `substrate.brief.result{surface,state,result}`, closed sets `BRIEF_STATES` / `BRIEF_RESULTS` (exported; `BriefDetail.state` is typed from `BriefState`), `recordBriefResult`; `observe.ts` hook `briefResult`.
4. **Per-surface SLO** — `packages/observability/src/slo.ts`: latency-quantile targets take an optional `where` (threaded into `mergeHistogram`); `briefBySurfaceObjectives(snapshot, thresholds) → SurfaceSloResult[]` — one `brief.p95` row per `surface` value of the brief histogram with ≥ `minSamples` (20), same `briefP95Ms` target, sorted, `{...SloResult, surface}`; `Observability.evaluateBriefSurfaces()`; `GET /slo` gains the sibling `surfaces` array after `docs`, never folded into `breached`.
5. **Smoke** — `scripts/grok-connector-smoke.ts` (`bun run smoke:grok`, `--json`): bearer for `grok-bot` only (`SUBSTRATE_TOKEN_GROK_BOT` first entry → `SUBSTRATE_TOKENS_DIR/grok-bot` (default dir from `packages/cli/src/token.ts`) → `SUBSTRATE_TOKEN`), never printed; checks `mcp.brief` (≤ 1500 ms, non-empty text, explicit state, `surface === grok-bot`), `mcp.brief.not_modified` (≤ 500 ms), `rest.brief.304` (200 then 304 with empty body), `healthz.planes` (`ok:false` or non-closed breaker → degraded). Exit 0 / 1 (degraded) / 2 (failed, unreachable, 401 with the hint naming variables, usage). Read-only: no event, retain or write. Reuses `parseBody` from `chaos-smoke.ts`.
6. **Docs** — `docs/grok-bot.md` (MCP contract table, `if_none_match`, the smoke, gateway adoption steps as the external dependency: conditional POST with a stored ETag per request context, propagate `X-Substrate-Brief`, docs via substrate `docs_search` = K5'), `docs/observability.md` (counter row, `surfaces` section, MCP note, route table).

## Flags and defaults

No new env variable. Every change is additive on the wire: the text block, the REST status/headers and the `/slo` arrays that existed are unchanged; `structuredContent`, `surfaces` and the counter are new fields. `if_none_match` only changes the reply when the caller sends it. The smoke is opt-in.
