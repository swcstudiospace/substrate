Append to the `# ── Documents: RAGFlow (retired) (Railway project "Agent Substrate")` block, after `SUBSTRATE_DOCS_STATE_FILE=`:

```sh
# The state file now holds the per-dataset version pins as well as the ingest
# records (file version 2; a version-1 file loads and is rewritten). The unit
# sets /var/lib/substrate/docs-ingest.json so citations keep their commit pin
# and a repeated merge-trigger stays idempotent across restarts (uplift-2 R6).
# Delete a superseded document after its replacement parsed, through the
# documented DELETE /api/v1/datasets/{id}/documents (uplift-2 R6). Off keeps
# every superseded document on the plane, exactly as before. 1 turns it on; a
# failed delete is logged and recorded on the ingest result, never a refusal.
SUBSTRATE_DOCS_PRUNE_SUPERSEDED=
# Retrieval knobs sent on every docs_search retrieval (uplift-2 R6). Defaults
# are RAGFlow (retired)'s own, so unset changes nothing on the wire; junk or
# out-of-range values fall back. similarity_threshold in [0, 1].
SUBSTRATE_DOCS_SIMILARITY_THRESHOLD=0.2
# vector_similarity_weight in [0, 1] — the documented legacy fallback of
# keywords_similarity_weight (0.7); the two sum to 1.
SUBSTRATE_DOCS_VECTOR_WEIGHT=0.3
# top_k, the number of chunks in the vector cosine pass (the reference marks it
# a deprecated alias of knn_top_k with the same default).
SUBSTRATE_DOCS_TOP_K=1024
```
