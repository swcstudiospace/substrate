# R2 — `.env.example` additions (orchestrator merges)

Append to the `# ── SLO thresholds` block, after `SUBSTRATE_SLO_MIN_SAMPLES=20`:

```sh
# Floor for every plane.<name>.availability objective (ok / all calls to that plane
# over the rolling hour, open-breaker refusals counted against it). Reported, never
# a status code. See docs/observability.md.
SUBSTRATE_SLO_PLANE_AVAILABILITY=0.99
```

New block, after the SLO thresholds block:

```sh
# ── Plane circuit breakers (uplift-2 R2) ──────────────────────────────────────
# One breaker per data plane (greptime, index, cache, hindsight, ragflow (retired)). After
# this many consecutive transport failures, timeouts or 5xx answers the plane is
# refused in microseconds instead of waited on, until the open window passes and
# one probe succeeds. Fail-open paths degrade exactly as for an unreachable plane;
# fail-closed paths stay closed. Set SUBSTRATE_BREAKER=0 to turn every breaker
# off (calls are still measured). Values outside the ranges fall back to the
# defaults. See docs/observability.md and docs/runbooks/substrate-red.md.
SUBSTRATE_BREAKER=
# Consecutive failures that open a breaker: integer 1..100.
SUBSTRATE_BREAKER_FAILURES=5
# How long an open breaker refuses before admitting one probe, ms: 1000..600000.
SUBSTRATE_BREAKER_OPEN_MS=30000
```
