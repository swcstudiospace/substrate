# R7 — `.env.example` additions (orchestrator merges)

Append to the `# ── MCP audit (SPE-4793)` block, directly after `SUBSTRATE_AUDIT_PATH=…`:

```
# Roll the audit file over by size: once the next record would take the active
# file past this many bytes it is renamed to <path>.<firstSeq>-<lastSeq>.jsonl
# beside it and a fresh file starts at the same path, chained to the closed one
# (one chain, several files; verify walks them all — `bun run audit:verify`).
# Unset or 0 never rolls. 50 MB is about two months at today's 0.9 MB/day.
SUBSTRATE_AUDIT_ROLLOVER_BYTES=
```

Not for `.env.example` (read from the operator's shell by `infra/vps/deploy-release.sh`, documented in `infra/vps/README.md`):

| Name | Default | Meaning |
|---|---|---|
| `SUBSTRATE_DEPLOY_MIN_FREE_GB` | `5` | refuse to build a release below this much free space on the release filesystem; `0` disables |
| `SUBSTRATE_HEALTH_REQUIRE_STORES` | `1` | after the `/healthz` poll, require `index` / `eventsWritable` for the stores the env file names, and no open breaker in `planes` |
| `SUBSTRATE_HEALTH_ENV_FILE` | `/etc/substrate/substrate.env` | the file whose `GREPTIME_URL` / `SUBSTRATE_PG_URL` *names* decide which stores are required (presence only, never a value) |
