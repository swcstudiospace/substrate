# R3 — `.env.example` additions (orchestrator merges)

Append to the `# ── Memory: Hindsight` block, after `HINDSIGHT_BANKS=`:

```sh
# Time bounds (uplift-2 R3), milliseconds; junk or zero falls back to the default.
# The shared abort budget of a memory_recall fan-out.
HINDSIGHT_RECALL_BUDGET_MS=4000
# The recall leg inside memory_search: shorter, so a slow plane never holds a
# search past it. A leg that misses it answers the index rows with
# degraded:true and a reason beginning `recall-timeout`.
HINDSIGHT_SEARCH_RECALL_BUDGET_MS=1500
# One retain POST.
HINDSIGHT_RETAIN_TIMEOUT_MS=8000
# HINDSIGHT_BANK (singular) is the legacy acc30a8 stub key: unread, and the
# server warns at boot when it is set. Use HINDSIGHT_BANKS above.
```

New block, after the Hindsight block and before `# ── Documents: RAGFlow (retired)`:

```sh
# ── Hindsight retain outbox (uplift-2 R3; docs/memory-governance.md) ──────────
# A retain forward that fails transiently (timeout, transport, open breaker,
# 5xx, 429) parks a locator here — never the text — and replays with backoff
# (30 s doubling to 1 h, ±20 % jitter), re-reading the entry from the index by
# id so a superseded memory is never replayed. Set the path for a 0600 JSONL
# file under the unit's StateDirectory so the queue survives a restart; unset
# keeps it in memory (retries until the process stops, then one warning per
# leftover). The unit sets /var/lib/substrate/retain-outbox.jsonl. Never the
# cache: Dragonfly is cache-only.
SUBSTRATE_RETAIN_OUTBOX_PATH=
# Most parked entries; over it the oldest is dropped with a `memory.retain.failed`
# warning (reason outbox-full).
SUBSTRATE_RETAIN_OUTBOX_MAX=10000
# Delivery attempts per entry, the live one included; the last failure emits the
# warning the forward used to emit at once. 1 restores the pre-R3 behaviour.
SUBSTRATE_RETAIN_MAX_ATTEMPTS=10
# How often due entries are replayed, ms. Also replayed after the first live
# retain that lands once the breaker had refused, and at shutdown.
SUBSTRATE_RETAIN_DRAIN_MS=30000
```
