# R1 — `.env.example` additions (orchestrator merges)

Append to the `# ── Hot cache: DragonflyDB` block, after `SUBSTRATE_CACHE=`:

```sh
# One cache command / one connect, ms (uplift-2 R1). Sized for the loopback redis
# production points at (sub-millisecond); a wedged server costs a brief at most
# this long before it bypasses the cache. Positive integers; anything else is 250.
SUBSTRATE_CACHE_COMMAND_TIMEOUT_MS=250
SUBSTRATE_CACHE_CONNECT_TIMEOUT_MS=250
```

New block, after the Plane circuit breakers block:

```sh
# ── Brief fast path (uplift-2 R1) ─────────────────────────────────────────────
# POST /brief and memory_brief read their four sources (index graph, ledger recent
# actions, index open graphs, index memory) together under one deadline. A read that
# misses it is a failed read: left out, logged, the brief still answers (fail-open,
# as before), marked X-Substrate-Brief: degraded. 0 = no deadline. See
# docs/observability.md.
SUBSTRATE_BRIEF_BUDGET_MS=1200
# How far back the recent-actions ledger read looks, days. Bounds the scan so an
# uncached brief never reads a repo's whole history. Positive integer; else 30.
SUBSTRATE_BRIEF_RECENT_WINDOW_DAYS=30
# How long the last complete brief per surface and arguments is kept in the cache
# (class brief-snapshot) to serve, with a dated banner line and
# X-Substrate-Brief: snapshot, while a live source is down. Never written while a
# source is down. 0 = no snapshots written or read.
SUBSTRATE_BRIEF_SNAPSHOT_TTL_S=3600
# How long a computed GET /healthz body is served again to pollers (cachedAt and
# stale in the body say so). Each computation is one round trip per configured
# plane, and every collector polls this route. 0 = recompute on every call.
SUBSTRATE_HEALTHZ_CACHE_MS=5000
```
