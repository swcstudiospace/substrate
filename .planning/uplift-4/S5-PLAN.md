## Change
1. `SUBSTRATE_BRIEF_RECALL=off|shadow|enforce` (default off). A bounded prefetcher (64-pair LRU wanted registry registered by `briefDetailed` with no I/O, 1 h expiry; interval tick default 120 s floor 30, at most 2 pairs older than half the TTL, single-flight; debounced 5 s refresh from `afterLiveRetain`) does ONE `recallBank` on the surface's OWN bank (never the `HINDSIGHT_BANKS` fan-out), budget low, `max_tokens` ≤ 400, query from the repo and ≤ 3 redacted subjects of 80 characters, post-filtered by `metadata.scope`, redacted, ≤ 3 hits of ≤ 240 characters; stored by `cache.put` in the generation-free class `recall-snapshot`, TTL 900 s; a failed or empty refresh never overwrites a good snapshot; deadline 1500 ms inside the breaker-gated call; skipped on an open breaker, no Hindsight config or no bank.
2. `briefDetailed` reads the snapshot with a cache read and hands it to `composeBriefSections` as a closure; new section `recall` with the lowest compact priority, `Recalled context (derived, Hindsight bank <bank>, <age> old):` plus ≤ 3 lines, only in `enforce` and only for a snapshot no older than 2× TTL. The mode is in the brief answer key and the brief-snapshot key; the section is part of the cached sections. Staleness bound documented (brief TTL + snapshot TTL).
3. `substrate.brief.recall{surface,result=included|would_include|cold|stale|disabled}` for every brief when the mode is not off; `substrate.recall.prefetch{surface,result=ok|empty|error|skipped_breaker|skipped_unconfigured|skipped_cache}`.
4. `SUBSTRATE_HINDSIGHT_INVENTORY=off|on` (default off, 60 s probe, floor 30): `listBanks` (≤ 200 banks, bounded pages), `bankStats`, `bankConfig` as read-only GETs with closed op labels, per-bank calls only for the ≤ 16 configured banks; gauges (`bank` label from the configured list only); drift report (names only, ≤ 20, sanitised); additive `/healthz.hindsight` block, absent when off. Retain outbox gauges (`size`, `oldest_age_seconds`, `durable`) from in-process stats, always on. Nothing is written to Hindsight.
5. Docs: BP-5.0 met in enforce; shadow-to-enforce procedure; staleness bound; bank isolation; what the gateway sees; rollback; `memory-recall.ts` header and the source test gate say the brief reads recall only from the cache.

## Acceptance
Off: brief text, ETag, cache keys byte-identical, zero Hindsight calls. Shadow: prefetch runs, `would_include` counted, text unchanged. Enforce: section with bank and age; cold, stale or failing snapshot omits it; compact drops it first with exact omitted counts; mode in cache and snapshot keys. Prefetcher: own bank only (several banks configured), scope post-filter, redaction, caps, registry LRU cap and expiry, single-flight, breaker skip, failed refresh keeps the previous snapshot, timers unref'd and cleared, debounce. Inventory: closed op labels, bank labels only from the configured list, bounded pages and caps, drift names bounded and sanitised, off by default with zero extra calls, outbox gauges always present. Source test: `brief.ts`, `brief-profile.ts`, `recall-snapshot.ts` never import `planes/hindsight`.
