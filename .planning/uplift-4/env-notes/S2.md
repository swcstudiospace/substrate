# S2 — environment names (not added to `.env.example`; the orchestrator merges this block)

All names are read from the process environment by `loadIndexArchiveSettings` (`packages/mcp-server/src/config.ts`) unless noted. No default changes today's behaviour.

| Name | Default | Meaning | Roll back |
| --- | --- | --- | --- |
| `SUBSTRATE_INDEX_ARCHIVE_DIR` | unset | Directory `substrate index archive` writes `index-<stamp>/` snapshots into. Unset: the command refuses by name (exit 2) and writes nothing; `/healthz.jobs.index` and the `/slo` `indexArchive` row are absent. Set it on the **server** as well (in `substrate.env`) to get the health row, gauge and SLO row. | Unset it (and restart `substrate-mcp`); disable the timer. |
| `SUBSTRATE_INDEX_ARCHIVE_MAX_AGE_H` | unset | Hours the newest complete archive may be old (`index.archive.age`). Unset or not a positive whole number: the row is `report-only`. Recommended `26` once the timer is installed. | Unset it. |
| `SUBSTRATE_INDEX_ARCHIVE_MAX_SECONDS` | `900` (10..86400) | Wall-clock bound on one export; past it the transaction rolls back and nothing is left on disk. | Unset it. |
| `SUBSTRATE_INDEX_ARCHIVE_MAX_BYTES` | `1073741824` (1 MiB..1 TiB) | Bytes one export may write. | Unset it. |
| `SUBSTRATE_INDEX_ARCHIVE_ALLOW_ROOTFS` | unset | `1`/`true`/`yes` waives only the dedicated-mount gate, for a deliberate local test on a one-disk machine. Read by the runner (`index-run.ts`) from the process env, like the ledger's. The unit never sets it; do not set it on the VPS. | Unset it. |
| `SUBSTRATE_INDEX_SCRATCH_URL` | unset | Scratch Postgres URL for `substrate index restore` when `--scratch` is omitted (preferred: an argument is visible in `ps`). Read by the runner only. Never printed; the restore refuses the URL when it names the same host, port and database as `SUBSTRATE_PG_URL`, and refuses outright when `SUBSTRATE_PG_URL` is unset. | Unset it. |
| `SUBSTRATE_INDEX_TUNE` | `off` | `apply` makes `IndexStore.migrate()` run, once and idempotently, `alter table graph_nodes set (fillfactor = 70, autovacuum_vacuum_scale_factor = 0.02)` after the DDL. Any other value is `off`. A failure is logged and does not stop boot. | Unset it; to undo the storage options: `alter table graph_nodes reset (fillfactor, autovacuum_vacuum_scale_factor)`. |

Reused, unchanged: `SUBSTRATE_DEPLOY_MIN_FREE_GB` (free-space floor, default 5, `0` disables), `SUBSTRATE_PG_URL` (the source, and the production URL the restore compares against).

Not environment, but operator steps: mounting the archive volume, installing `infra/vps/substrate-index-archive.{service,timer,service.d}`, enabling the timer.
