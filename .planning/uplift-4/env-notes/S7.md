# S7 environment variables

Nothing here is installed by code. Railway variables and the canary drop-in lines are operator steps.

| Name | Where | Default | Meaning | Rollback |
| --- | --- | --- | --- | --- |
| `SUBSTRATE_DOCS_FRESHNESS_MAX_AGE_H` | substrate-mcp | `168` (range 0-8760; garbage falls back) | Report-only staleness threshold in hours for `docs.freshness` (a dataset whose newest `versions[].ingested_at` is older is `stale`). `0` reports the age without judging it. | Set `0` (age no longer judged); unset restores 168. |
| `SUBSTRATE_DOCS_TRIGGER_LAG_MIN` | substrate-mcp | `15` (range 0-10080; garbage falls back) | Minutes an accepted merge-trigger may wait for a recorded version with its commit before the dataset is `lagging` (gauge, `/slo` detail, one `warning`). `0` stops recording accepted triggers and detecting lag. | Set `0` and restart. Triggers already in the state file are ignored; a left-over marker clears with one `note`. |
| `SUBSTRATE_DOCS_LAG_CHECK_S` | substrate-mcp | `60` (range 15-3600; garbage falls back) | Seconds between the unref'd timer passes that settle the lag `warning`/`note` (`/slo` and `/metrics` only read). | Set `3600` to make passes rare; with `SUBSTRATE_DOCS_TRIGGER_LAG_MIN=0` a pass does nothing. |
| `SUBSTRATE_DOCS_CANARY` | `substrate-docs-canary.service.d/10-environment.conf` (commented line) | unset (refuses, exit 2) | Opt-in for the live golden canary. Must be exactly `1`. | Comment the line / `systemctl disable --now substrate-docs-canary.timer`. |
| `SUBSTRATE_DOCS_CANARY_MANIFEST` | same drop-in (commented line) | unset (refuses, exit 2) | Path of the operator-attested JSON `{"sha256", "dataset_commit"}` written after ingesting `fixtures/docs-golden/corpus`. | Comment the line. |
| `SUBSTRATE_DOCS_CANARY_STATE` | `substrate-docs-canary.service` (`Environment=`) | `/var/lib/substrate/docs-canary-last.json` | The dedupe record (failing fixture ids last announced). | Delete the file to allow one repeat warning. |

Variables the canary only reads (already defined elsewhere): `SUBSTRATE_URL` (default loopback; the canary refuses a non-loopback host), `SUBSTRATE_TOKEN_OMP` (search bearer; list-valued: first entry), `SUBSTRATE_TOKENS_DIR`, `SUBSTRATE_TOKEN`, `SUBSTRATE_TOKEN_SUBSTRATE` (emit bearer; first entry of a list).

`.env.example` and `.planning/STATE.md` are NOT edited by this item; the orchestrator should add the two substrate-mcp names to `.env.example`.
