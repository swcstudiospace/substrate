# S5 env notes (cross-session recall in the brief, Hindsight inventory)

Add to `.env.example` / `docs/observability.md` env table at merge (the docs table already carries these rows). All six are read by `substrate-mcp` only (`config.ts`, parsed in `recall-snapshot.ts` and `hindsight-inventory.ts`), from the process environment (`Environment=` / `EnvironmentFile=`). None takes a list value, so the "first entry of a token list" rule does not apply. A value that is junk falls back to the default (or the floor/ceiling) and is named once at boot (`[substrate] misconfigured — …`), never thrown.

| Name | Default | Meaning | Rollback |
| --- | --- | --- | --- |
| `SUBSTRATE_BRIEF_RECALL` | `off` | `off`: no prefetcher, no timer, no cache read, no Hindsight call; brief text, ETag and cache keys exactly as before. `shadow`: the prefetcher runs, every brief is counted in `substrate.brief.recall{result}` (`would_include` when a fresh snapshot exists), the served text is unchanged. `enforce`: a `Recalled context (derived, Hindsight bank <bank>, <age> old):` section of at most three lines is appended. Case-insensitive; anything else is `off`, named at boot. The mode is part of the brief cache key and of the last-good snapshot key. | `SUBSTRATE_BRIEF_RECALL=off` and a restart (operator step). Snapshots expire by TTL; no flush. |
| `SUBSTRATE_BRIEF_RECALL_INTERVAL_S` | `120` | Seconds between prefetch ticks; each tick refreshes at most two wanted `(surface, repo)` pairs whose snapshot is older than half the TTL. Whole number, floor 30, ceiling 3600. | Set `SUBSTRATE_BRIEF_RECALL=off`. |
| `SUBSTRATE_BRIEF_RECALL_TTL_S` | `900` | Snapshot TTL in the `recall-snapshot` cache class, seconds (60–86400). The cache entry lives twice this: a snapshot up to this old is `fresh` (carried in `enforce`), older up to twice this is `stale` (omitted but counted: the prefetcher is behind), beyond that the entry is gone (`cold`). | Set `SUBSTRATE_BRIEF_RECALL=off`. |
| `SUBSTRATE_BRIEF_RECALL_BUDGET_MS` | `1500` | Deadline of one recall, as the abort signal inside the breaker-gated fetch (100–10000); a timeout counts as a plane failure. | Set `SUBSTRATE_BRIEF_RECALL=off`. |
| `SUBSTRATE_HINDSIGHT_INVENTORY` | off | `on`: the read-only inventory probe (bank list, per-configured-bank stats and config), per-bank gauges, the drift report and the additive `/healthz.hindsight` block. Case-insensitive; anything else is off (a value other than `on`/`off`/empty is named at boot). Nothing is written to Hindsight. | `SUBSTRATE_HINDSIGHT_INVENTORY=off` and a restart. |
| `SUBSTRATE_HINDSIGHT_INVENTORY_INTERVAL_S` | `60` | Seconds between probes (floor 30, ceiling 3600). | Set `SUBSTRATE_HINDSIGHT_INVENTORY=off`. |

Recall needs the cache (`DRAGONFLY_URL`, `SUBSTRATE_CACHE` not `0`): with it off and `SUBSTRATE_BRIEF_RECALL` not `off`, boot warns and no recall is sent. Recall is for a bearer that is the surface the brief names; an anonymous caller or a mismatched surface gets none. A pair is not recalled twice within 30 s.

Not flags: the retain outbox gauges (`substrate.hindsight.retain_outbox.size|oldest_age_seconds|durable`) are in-process, always on, and make no external call. Constants in code: wanted registry min(32, 8 x (TTL/interval - 1)) pairs / 1 h expiry (32 at the defaults; `/healthz.recall` reports `capacity`, `wanted`, `saturated`; boot warns when below 32), ceil(wanted / ticks per half TTL) pairs per tick up to 8, 8 pairs per post-retain flush, 5 s retain debounce, snapshot caps 3 hits × 240 characters, query at most 3 subjects × 80 characters, `max_tokens` 400 (the plane client's default), inventory 50 banks per page / 200 banks / 16 per-bank probes / 20 drift names per list / 10 s probe deadline / 60 s memo.

Reads of the Hindsight env: `HINDSIGHT_URL`, `HINDSIGHT_API_KEY`, `HINDSIGHT_BANK_PREFIX` and `HINDSIGHT_BANKS` are read, as before, only through `hindsightFromEnv()` / `hindsightBanksFromEnv()` in `planes/hindsight.ts`; this item adds no new consumer of them outside `service.ts`'s existing calls. The bank list (`HINDSIGHT_BANKS`) is comma or whitespace separated and already handled there; the recall prefetcher ignores it (own bank only) and the inventory uses it only as the configured-bank list.

Suggested `.env.example` block:

```
# Cross-session recall in the brief (uplift-4 S5): off | shadow | enforce. shadow only counts would_include.
# SUBSTRATE_BRIEF_RECALL=off
# SUBSTRATE_BRIEF_RECALL_INTERVAL_S=120
# SUBSTRATE_BRIEF_RECALL_TTL_S=900
# SUBSTRATE_BRIEF_RECALL_BUDGET_MS=1500
# Read-only Hindsight bank inventory, gauges and drift report (uplift-4 S5): on | off.
# SUBSTRATE_HINDSIGHT_INVENTORY=off
# SUBSTRATE_HINDSIGHT_INVENTORY_INTERVAL_S=60
```
