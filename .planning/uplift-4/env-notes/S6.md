# S6 env notes (orchestrator applies)

## `.env.example` block

Place after the `SUBSTRATE_SLO_*` lines (next to the SLO checkpoint and notifier block).

```sh
# ── Durable metrics history (uplift-4 S6) ───────────────────────────────────
# SUBSTRATE_METRICS_HISTORY=on samples a fixed allow-list of SLO and plane series
# (brief p50/p95 per surface, emit success, plane availability and p95, cache hit
# ratio, admission decisions, docs search outcomes, capacity runway) every
# SUBSTRATE_METRICS_HISTORY_INTERVAL_S seconds into the `metric_samples` table of
# the event ledger's database, and serves them at GET /slo/history. Off by default;
# off means no timer, no table, no route payload. Also needs the event ledger (GREPTIME_URL); without it it stays off and boot says why.
SUBSTRATE_METRICS_HISTORY=
# Seconds between samples. Default 60, floor 15, ceiling 3600.
SUBSTRATE_METRICS_HISTORY_INTERVAL_S=
# Retention, put in the CREATE TABLE: whole days, 1d to 90d, default 14d. Anything
# else falls back to 14d and is named at boot. An existing table keeps the
# retention it was created with (changing it is an operator ALTER).
SUBSTRATE_METRICS_HISTORY_TTL=
```

## Variables

| Name | Default | Meaning | Rollback |
| --- | --- | --- | --- |
| `SUBSTRATE_METRICS_HISTORY` | `off` | `on` (any case) starts the sampler and enables `/slo/history`; any other value is off and is named at boot. | Unset or `off`, restart. The table stays and expires on its TTL; `DROP TABLE "metric_samples"` is an operator action. |
| `SUBSTRATE_METRICS_HISTORY_INTERVAL_S` | `60` | Seconds between samples; clamps to 15..3600. | Unset. |
| `SUBSTRATE_METRICS_HISTORY_TTL` | `14d` | `<1-90>d`, strict pattern, used only when the table is created. | Unset (an existing table keeps its TTL either way). |

Consumers: read only by `loadConfig` in `packages/mcp-server/src/config.ts`, so only the
`substrate-mcp` unit (via `/etc/substrate/substrate.env`) sees them. There is no per-unit
spelling and none of them is list-valued.

## `package.json` scripts

None.

## Unit

None. No systemd unit, timer or Railway variable ships with this item. The sampler is an
in-process timer; enabling it is `SUBSTRATE_METRICS_HISTORY=on` in `/etc/substrate/substrate.env`
(an operator step) and a restart.
