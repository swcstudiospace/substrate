# S1 — `.env.example` additions (orchestrator merges)

No `package.json` script lines. Six new variables, all read by `substrate-mcp` only (`config.ts` → `brief-profile.ts`; the ceiling by `GET /slo`).

Insert as its own block after the `SUBSTRATE_BRIEF_*` lines (uplift-2 R1):

```sh
# ── Brief profile (uplift-4 S1; docs/grok-bot.md § The brief profile) ─────────
# Which rendering of the brief a caller is served. off: everyone gets the full
# text, no compact text is built. shadow (the default): everyone still gets the
# full text; the compact text is built and substrate.brief.profile_bytes_saved
# records what it would have saved. enforce: the surfaces below get a capped,
# state-carrying `compact` brief; a caller may pass profile=full (always wins) or
# profile=compact. Anything else is shadow, with a boot warning. Roll back by
# setting shadow or off and restarting; cached entries need no flush.
SUBSTRATE_BRIEF_PROFILE=shadow
# Surfaces served compact under enforce when the caller names no profile. Comma
# or whitespace separated, closed against SURFACES; unknown names are ignored
# with a boot warning, and a list with no known surface is the default.
SUBSTRATE_BRIEF_PROFILE_SURFACES=grok-bot,grok-build
# Compact limits: node lines (1..200), characters per memory line (40..4000),
# and the hard cap on the rendered text in UTF-8 bytes (512..65536; the omitted
# line counts toward it). Out-of-range values are clamped, with a boot warning.
SUBSTRATE_BRIEF_COMPACT_NODES=12
SUBSTRATE_BRIEF_COMPACT_MEMORY_CHARS=240
SUBSTRATE_BRIEF_COMPACT_BYTES=3500
# Estimated-spend ceiling for the per-surface served.tokens_est rows of GET /slo:
# tokens per rolling hour, estimated as bytes/4 of brief, recall and docs replies.
# Unset (the default) reports the rows `unconfigured` and never judges them. Not
# the model-reported burn: SUBSTRATE_BURN_TOKENS_PER_HOUR is unchanged.
SUBSTRATE_SERVED_TOKENS_PER_HOUR=
```

Rollback: `SUBSTRATE_BRIEF_PROFILE=shadow` (or `off`) and a restart of `substrate-mcp` — an operator step on the unit environment; no code or unit file changes. Leaving `SUBSTRATE_SERVED_TOKENS_PER_HOUR` unset is the default and judges nothing.
