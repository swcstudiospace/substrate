# 13-01: Signed handoffs at accountable-agent boundaries, context rebuilt from the ledger

## Objective
Context that crosses an accountable-agent boundary is written down by its sender as a signed `coord_handoff` packet and can be replayed from the ledger alone (ADR 0001 S2 criteria 7-9 and the proof, swarm side).

## Tasks
1. `swarm/substrate_client.py`: factor `own_token(env, surface)` out of `_token`, with the same results.
2. `swarm/substrate_lease.py`:
   - `has_own_token(surface, env)` sits next to `_call`. The two are the token seam that Phase 14 swaps.
   - `LeaseBridge.handed_over(task_id)` drops a lease released by a handoff and mirrors `released` / `handover`.
3. `swarm/substrate_handoff.py` (new):
   - `boundary()` builds and fits a packet under 9 kB, with key line `boundary: <round>/<part>`.
   - `escalation_owner()` returns A14 when a direct upstream task is A14's, else A01.
   - `HandoffBridge(store_path, correlation_id, *, emit, root, env, leases)`:
     - `dispatched(task, agent_id)`: dependency packets.
     - `gate_failed(task_id, failing, verdicts, rework)`: gate agent → producer.
     - `escalated(task_id, *, reason, failing, verdicts)`: producer → A14/A01, handing over a held lease.
     - `send`, `flush` and `context(task_id, agent_id)`.
     - Idempotency comes from one `coord_handoff_list` read per process, keyed on (sender surface, key).
     - Fail-open: `handoff.unsent` and retry, or `handoff.refused`.
     - `handoff.unsigned` once; `handoff.misattributed`.
   - `reconstruct(graph_id, node_id, *, agent, env) -> Context` reads `coord_handoff_list` and `events_query` only. `trust_of` maps the server's verdict to verified, unsigned or rejected. `render(ctx)` builds the prompt section.
4. `swarm/substrate_tee.py`: `TYPE_KINDS` maps `handoff.unsent`, `handoff.refused`, `handoff.unsigned` and `handoff.misattributed` to `warning`.
5. `swarm/results.py` `reconcile(..., handoffs=None)`:
   - `gate_failed` after CHANGES_REQUESTED → IN_PROGRESS, using the verdict rows read before the transition.
   - `escalated` before `settle` at the rework cap.
6. `scripts/swarm_run.py`:
   - `handoff_bridge()` is on exactly when leases are.
   - `dispatchable(..., handoffs=)` calls `escalated` at `max_attempts`.
   - `execute_one(..., handoffs=)` writes the dependency packets and passes `context` into `assignment_prompt(..., handoffs=)`.
   - `run()` calls `flush()` each round and after the last.
7. `tests/test_substrate_handoff.py`, using test_substrate_lease's fake plus `coord_handoff`, `coord_handoff_list` and `events_query`. It covers:
   - each boundary written by its sender's token, with no sender argument and an exact caller per packet
   - A05's packet re-labelled as A14's fails verification
   - a missing own token → nothing sent, and no fallback to A01's token
   - a token under another agent's name → misattributed
   - `dod` from `acceptance[]`, `files` from outputs, and the sessions
   - same-agent edges skipped
   - a gate's findings → blockers
   - the rework cap → A14 with the lease handed over (release after the packet, no second release), and A14 can claim
   - `max_attempts` → A01
   - HAND-02: A14 rebuilds from list + query with the state directory deleted, `TaskStore.__init__` failing and an audit hook on open/connect, exactly two calls made as A14, and a tampered packet listed but not used
   - HAND-03: a full `swarm_run.run` with no key completes, packets are unsigned, `handoff.unsigned` is recorded once and the prompt says UNSIGNED
   - idempotent re-runs and restarts, with a quoting packet from another surface not suppressing the real one
   - unreachable → warn once, the task runs, `flush` sends later
   - `stored: false` retried; refused not retried
   - no bridge without leases
8. Docs: `docs/substrate-handoffs.md` (new). Update `docs/substrate-leases.md` (seam, ESCALATED handover, limits) and `docs/substrate-tee.md` (type table, "Not in S1").
9. Live proof `/tmp/p13-proof.sh` (PROOF-02).

- Deleting or rewriting anything in the Task Store (criterion 10).
