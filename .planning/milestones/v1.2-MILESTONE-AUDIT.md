### Findings closed during integration

- **LW-01 (INST-01):** omp mounted the substrate tools but its blanket MCP guard blocked every invocation. The runner now marks only the exact projected entry after resolving the agent's own token. The guard admits only the known substrate API for that matching session; unrelated MCP and lookalike tools remain blocked, and A01's depth cap still takes precedence. The regression failed before the fix. The full extension suite and actual runtime tool-loop proof pass after it.
- **LW-02 (LEASE-05):** a competing-replica regression call omitted the new required `workspace` argument. The call now uses the fixture workspace; the final 743-test workspace suite passes.
- **Expired-claim congestion:** a locally busy re-claim was treated as a server refusal and stopped running work. It now defers until capacity returns without killing the dispatch. The failing-before/passing-after regression and real PostgreSQL expiry/saturation scenario pass.
