# v1.7 requirements audit (41 requirements)

Audited against `main` at a7fbcb3a (PR #194). Method: each requirement in `.planning/REQUIREMENTS.md` was checked by reading the implementation, grepping the named tests, and reading the docs. Nothing was run: no tests, no live server, no devnet, no LightRAG. Evidence paths are `packages/...` unless stated otherwise. Anything not read is `[INFERENCE]`.

Strict rule: a requirement is MET only when its behaviour is on by default or the requirement does not say it must be on, the code path exists, and a test exercises it. A behaviour that is off by default, staged but not installed, or proven only against a fake server is PARTIAL.

## Open findings (defects and drift found by this audit)

Not fixed in this pass. Each needs an owner decision on priority.

- **F1 (ATLAS-04, security, high once the corpus flag is on).** `POST /corpus/ingest` accepts a tombstone for any `{repo, path}` from an authenticated caller, with no scope or tier check (`validate.ts:168-178`, `ingest.ts:476`). The client plan limits this only for the CLI.
- **F2 (REFLECT-02, integrity, medium).** `session_id` is caller-supplied, so one caller can stack feedback votes (`authority-index.test.ts` seeds sessions a, b, c to reach `STALE_FEEDBACK_MIN`).
- **F3 (WATCH-05, low to medium).** `docs.sync` is not in `RESERVED_NOTE_ACTIONS` (`reserved-actions.ts:23-30`), so any authenticated caller can set the lag gauge.
- **F4 (ATLAS-05, medium).** An interrupted run between a plane insert and the superseded-document delete leaves an orphan. Only `corpus reconcile --execute` removes it.
- **F5 (FLEET-01, medium, functional).** The dispatcher ignores `SUBSTRATE_WORKTREE_ROOTS`, and the collector falls back to a hard-coded root.
- **F6 (EVAL-05, low, docs).** `docs/runbooks/docs-rag-operations.md` §5, §6 and §10 disagree with the code (re-rank reader and sync units). The phase 70 record repeats the stale claims.
- **F7 (WATCH-02 and REFLECT-05, medium).** Planning pages re-ingest on restart unless the flag is on. An unchanged digest is never retried after a refused retain.
