  - `CACHE_TTL` (`cache.ts:52`): add `shared: 300` (the `context` kind's TTL; the store-level per-kind values below govern every real write). `shapeOk()` (`cache.ts:1343`): a shared value is any JSON round-trippable value — string, number, boolean, null, array or object (an `undefined`, function, symbol or bigint is never storable; `JSON.stringify` would drop or throw it, so it is never a served value). Context is text, output/recall are objects; one permissive lane shape keeps the classes closed without inventing per-kind shapes.
  - `ReadThroughCache` primitives on the caller's exact key (no hash, no generation — the namespace itself is the key), all through the existing `attempt()` deadline, `count()` and `fail()` paths (`cache.ts:1220`, `cache.ts:1241`):
    - `getShared<T>(key): Promise<T | null>` — gate-aware read like `peek()` (`cache.ts:1011`): cache off → `null`; gate blocked → counts one `bypass` (the lane's fallback read is this call, so the bypass belongs here, unlike `peek` whose caller already counted one) and returns `null`; absent/expired → counts one `miss`, `null`; malformed envelope → counts `error` + `bypass`, `null`; failing command → `fail(cause, true, "shared")`, `null`. Never throws; an expired key is a miss, so the store re-loads and stale is never served.
    - `putShared(key, value, ttlSeconds): Promise<boolean>` — via the existing `writeKey()` (`cache.ts:1116`): envelope `JSON.stringify({ v })`, `SET … EX ttl`; `ttlSeconds <= 0` or bad shape writes nothing and returns `false`; a failing write counts `error` without a bypass (the caller already has its answer, `cache.ts:1131`). Writes are not gate-blocked — DG-1b leaves the write path for the probe (`cache.test.ts:2206` gate block comment); a write under a blocked gate is simply never read back until the gate allows.
    - `claimShared(key, claimId, ttlSeconds): Promise<"won" | "lost" | "bypass">` — one round trip through `script()` (`cache.ts:1145`, which is the `eval` seam): Lua `if redis.call("exists", KEYS[1]) == 1 then return 0 end; redis.call("set", KEYS[1], ARGV[1], "EX", ARGV[2]); return 1`. `1` → `"won"`, `0` → `"lost"`; script `ok: false` (no `EVAL`, timeout, failure — `script()` already counted the `error`) → `"bypass"`; cache off or gate blocked → `"bypass"` without sending a command. Never throws. The claim key is the caller's namespaced slot key plus `":claim"`, holding the bare `claimId` (not an envelope — values live on the value key).

## Task 2 — `fabric/shared-context.ts` store + `fabric/shared-context.test.ts`

New file `packages/mcp-server/src/fabric/shared-context.ts` (fabric placement follows `dragonfly-readiness.ts`, which is the gate's home; the store is gate + cache, not a second client). It imports `CACHE_PREFIX`, `canonical`, `ReadThroughCache` (type), `DragonflyGateMode` from `../cache.ts`, and `dragonflyGateVerdict` from `./dragonfly-readiness.ts` — function-body use only, the same no-module-scope-cycle pattern `cache.ts:39` documents.

- Namespace (CONTEXT: `substrate:v1:shared:<agent>|<graph>|<kind>:<stable-key>`):
  - `SHARED_PREFIX = substrate:v1:shared:`; `sharedKey(agent, graph, kind, stableKey)` builds `substrate:v1:shared:<agent>:<graph>:<kind>:<stable-key>` (both scopes are always present; `"-"` is the agent-global graph spelling). `parseSharedKey(key)` is the exact inverse, or `null` for anything else. Agents are the closed set `herdr | claude-code | grok | reminiscent`; kinds are `context | output | recall`; `graph` and `stableKey` are `[A-Za-z0-9._-]` segments (no `:` — it is the separator). An invalid segment throws `TypeError` (bounded message, programmer error — never a runtime fallback path).
  - `stableSharedKey(args)` = hex `sha256(canonical(args))` for callers holding arguments instead of a key (`canonical`, `cache.ts:293`).
- Per-kind TTL: `SHARED_KIND_TTL = { output: 60, context: 300, recall: 600 }` with `sharedTtlS(kind)`; every `putShared` and every claim uses the kind's TTL, never `CACHE_TTL.shared` directly.
- `SharedContextStore` wraps one `ReadThroughCache`. The cache is the single owner of the gate: `ReadThroughCache.gateAllows()` is public since E2 (`cache.ts:600`, wired from `SUBSTRATE_DRAGONFLY_GATE` by `createReadThroughCache`), and the store has no `gateMode` of its own, so reads, write-skips and claims can never disagree about it. The rule is `off` never reads the verdict; `enforce` requires the last DG-1a verdict `ok` or `degraded` (`dragonflyGateVerdict("enforce")`, `dragonfly-readiness.ts:81`; `degraded` serves, `unavailable`/`unconfigured` blocks), re-read per call, never baked into construction:
  - `getOrLoad<T>({ agent, graph, kind, stableKey, load })` — `cache.getShared(key)` first, so the read is gated and counted by the cache (`getShared` counts one `bypass` on a gate block, one `miss` on absent/expired). Hit → the value. Any null → `value = await load()` (the durable read, never stale), then `cache.putShared(key, value, sharedTtlS(kind))` only when `cache.gateAllows()` still holds (a gate-blocked load is never stored — the entry would be invisible until the gate allows, and skipping it matches the read-through cache's own blocked path, `cache.ts:658`). Write failure keeps the loaded value (`writeKey` semantics, `cache.ts:1128`).
  - `get<T>(…): Promise<T | null>` — the shared-lane `peek`: gate/cache-off → `null` (callers compose live; the durable load is the caller's `request.load()` at its own layer).
  - `claim({ agent, graph, kind, stableKey, claimId }): Promise<"won" | "lost" | "bypass">` — `claimId` non-empty, ≤ 256 chars, else `TypeError`; gate blocked or cache off → `"bypass"` (increments the store's own `claimBypasses`, never throws, sends no command); else `cache.claimShared(slotKey + ":claim", claimId, sharedTtlS(kind))`, counting `claimsWon`/`claimsLost`/`claimBypasses` for the three answers. The claim is an advisory single-writer election: a `"lost"` caller still answers from its own durable `load()` and writes nothing, so correctness never depends on winning.
  - `put({ agent, graph, kind, stableKey, value }): Promise<boolean>` — `cache.putShared(key, value, sharedTtlS(kind))`.
  - `health()` — the underlying `cache.health()` (hits/misses/bypasses/errors already counted under class `"shared"`) plus `claimsWon`, `claimsLost`, `claimBypasses`. Bypass counting stays single-owned by the cache primitives; the store adds only the claim counters.
  - `createSharedContextStore(cache)` factory beside the class.
- `fabric/shared-context.test.ts` (fakes only, no live server, no real sleep — the `dragonfly-readiness.test.ts` pattern): namespace build/parse round-trip and the exact `substrate:v1:shared:` prefix; invalid agent/kind/graph/key/claimId throws; TTL map pins (`output 60`, `context 300`, `recall 600`); `getOrLoad` miss → load → hit on the second call with `load` run once and one `SET` with the kind TTL; expired key → `load` again, never the stale value (fake TTL expiry at a controllable `now`); gate matrix — `off` + unavailable verdict serves like today, `enforce` + `ok` serves, `enforce` + `degraded` serves, `enforce` + `unavailable` and `enforce` + no verdict (`unconfigured`) bypass to `load` with a counted `bypass` and the value never served even when present, `enforce` + blocked `get` returns `null`; cache off (`redis: null`) → `load`, `get` → `null`, `claim` → `"bypass"`; claim — first claim `"won"`, concurrent second claim on the same slot `"lost"`, different slots both `"won"`, gate-blocked claim `"bypass"` with no command sent, claim under a client without `EVAL` → `"bypass"`.

Acceptance: `bun test fabric/shared-context.test.ts` green (all cases above); every fallback path returns `request.load()`'s value with `bypasses` incremented and no cache value served; no throw path except the key/claimId `TypeError`s.
