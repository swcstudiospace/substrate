| Boundary | Description |
|----------|-------------|
| collector → POST /events over loopback | Server reply codes are the durability truth; the client must not trust-and-forget |
| refused-emits.jsonl + journal stderr | Operator-visible files; must never carry secrets, tokens, summaries or payloads |
| cwd → git CLI → repo slug | Untrusted directory names flow into stored repo fields |
