# U5-2 env notes (lines for `.env.example`)

Read by `scripts/doctor-runtime.ts` (host-side doctor), not by the MCP server. Set it in
`/etc/systemd/system/substrate-doctor.service.d/10-environment.conf` for the timer, or in the shell for a manual run.

```
# Runtime doctor (uplift-5 U5-2): highest `systemd-analyze security` exposure score, 0-10, a substrate unit may have.
# Unset (default) = the doctor only REPORTS each unit's score and never changes its exit code.
# A number (e.g. 6.5, the highest staged ceiling) makes a unit above it `drift` (exit 2).
# Not a number from 0 to 10 = one `warn` row and the rows stay report-only.
# SUBSTRATE_EXPOSURE_MAX=
```
