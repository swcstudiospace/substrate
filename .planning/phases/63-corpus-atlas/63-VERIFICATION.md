## Residual risks

- **No rename across repositories** for moved identical copies: the plane document is deleted and rewritten under the new name, a full re-parse of that text.
- **The manifest is outside the archive.** A lost `corpus_documents` is rebuilt by a full ingest (every document is a same-name conflict that is cleared and rewritten); no restore path was tested.
- **Plane provenance is thin.** A search hit carries repo, path and sha through the document name; kind, tier and commit need a manifest lookup.
- **`corpus_ingest` is not operator-only.** Any authenticated, non-VM-guest surface that passes admission can write the shared dataset and delete plane documents.
- **Single flight is per process** (`docs/runbooks/corpus-ingest.md`, "Order of work inside a request"); with two server processes the phase ordering is not enforced between them. [INFERENCE: not tested.]
- The Postgres-backed store tests (`packages/mcp-server/src/corpus/store.test.ts`) run only when `SUBSTRATE_TEST_PG_URL` is set; this record does not know whether CI had it set.
- The measured inventory in the CONTEXT (44 origins in 72 checkouts) was not repeated here.
