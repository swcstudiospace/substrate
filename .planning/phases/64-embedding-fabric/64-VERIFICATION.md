## Residual risks

- **Criterion 3:** the breaker is visible only as a changed `state`; an operator cannot tell an open breaker from a failed `/health` in `fabric_status` alone. Either add a reading to the row or change the doc sentence.
- TEI was never contacted: the wire contract (`/embed` body, `/info` field names `model_id` and `max_client_batch_size`, `Retry-After`) is checked only against the fake in the tests.
- The compliance check classifies the URL (loopback, listed proxy, direct); it cannot tell that a loopback forwarder leads to a private service.
- The near-duplicate comparison is pairwise (`NEAR_DUPLICATE_MAX_ITEMS` 5000, request cap 1000 excerpts). A larger corpus is compared only up to `--neardup-max`, and a document whose first 4000 characters match another's is reported even when the rest differs.
- A file swapped for a symlink between scan and excerpt read is guarded (`cli/src/corpus/neardup.test.ts` `"a document replaced by a symbolic link after the scan is not followed: its target's text is never read or sent"`); where the platform has no `O_NOFOLLOW`, only the regular-file and size checks apply (`docs/corpus.md`).
- The seven review rounds on #179 were mostly in the model-check state machine; its concurrency is covered by fake-clock tests only.
