# 14-01: substrate-mcp wired into every swarm workspace, one token per agent process

## Objective
A fresh swarm workspace is wired to `substrate-mcp` by `build_agents.py --install-workspace` alone, and each agent process (and the lease the runner holds for it) uses only that agent's own token (ADR 0001 S4).

## Tasks
1. agent-substrate `packages/projector/src/swarm-workspace.ts` (new; library + Bun CLI):
   - `RUNTIME_FILES`: claude and omp → `.mcp.json` (JSON); grok → `.grok/config.toml` (TOML).
   - Exports `jsonEntry`, `tomlBlock`, `spec`, `plan`, `apply` and `describe`.
   - Rules: append and never replace; idempotent; refuse a differing `substrate` entry, unparsable input, an inline `mcp_servers` table, symlinks, unknown runtimes and a missing workspace; all-or-nothing; `.substrate-backup`; atomic rename.
   - CLI modes `--plan`, `--check` (exit 1 on pending changes), `--apply` and `--spec`; exit 2 on refusal.
   - `package.json` `main` points at it.
2. agent-substrate `swarm-workspace.test.ts`, driving the CLI over a temp workspace with a sentinel token in the environment:
   - one entry per file;
   - no Greptime MCP server in any generated file, and no sentinel in any file under the workspace;
   - existing entries kept, backups written, a second run changes nothing, `--check` reports 0 then 1;
   - an identical hand-written entry is accepted;
   - each refusal exits 2 and writes nothing;
   - `trae` is refused.
3. agent-substrate `store-lock.test.ts`:
   - `TOKEN_LITERAL` scan over tracked files, plus detector cases for each name and file shape, and for placeholders, references and fixtures that must not fire;
   - the projector glob excludes `*.test.ts`.
4. agent-swarm `swarm/substrate_mcp.json` (the vendored `--spec`) and `swarm/workspace.py`:
   - `SPEC`, `CLAUDE_TOOLS`, `carries_token`, `server_var`, `mcp_config`, `env_dir`, `env_file`;
   - `read_token` (0600, owner, one line), `write_token` (0600 from the first byte, rename), `agent_token`, `child_env`.
5. agent-swarm `scripts/_install_substrate.py` (new): `plan_mcp`, `plan_env`, `location_problem`, `operator_instructions`, `runtime_problem`, `plan`, `preflight(tokens=)` and `install_substrate(dry_run)`.
   - `build_agents.py`: `--runtimes` and `--no-substrate`; substrate preflight before generation; the dry run prints the substrate plan; the real run runs the substrate step before the copies.
   - `render_claude` adds `mcp__substrate` to `tools:`, and `.claude/agents/*.md` are regenerated.
6. agent-swarm `scripts/swarm_run.py` `headless_command`:
   - `child_env` from the agent's env file;
   - claude: `--mcp-config <ws>/.mcp.json --strict-mcp-config` and `mcp__substrate` in `--allowedTools`;
   - grok: `--trust`, only when the workspace has the entry;
   - `dry_run_invocation` adds the token names to the unsets and prints a token-source line.
7. agent-swarm `swarm/substrate_lease.py`:
   - `_call(tool, args, agent_id, workspace, env)` reads the env file and refuses with the file's name;
   - `Lease.workspace`, `claim_node(workspace=)`, `LeaseBridge(root)` and `settle_mirrored(workspace=)`;
   - `orch_status` passes `ctx.root`.
8. Tests (agent-swarm):
   - `tests/test_install_substrate.py`, which runs the CLI from a copy of the checkout into a fresh git workspace. It covers:
     - the entries;
     - kept entries and an idempotent re-run;
     - no Greptime and no token under the workspace;
     - env files that are 0600, in a 0700 directory, outside every checkout and holding exactly one token;
     - a missing token (operator message, exit 2, nothing written);
     - an operator-created file kept, and a 0644 one refused;
     - an env directory inside a git checkout or inside the workspace refused;
     - `trae` refused;
     - every existing refusal still writing nothing with tokens given;
     - the dry run's additions, env files and lack of token values, and its exit 2 with a missing token;
     - `--no-substrate`.
   - `tests/test_agent_token.py`:
     - each runtime's child holds only its own token, and no token without a file;
     - the claude, grok and omp argv;
     - the live omp child via the stub;
     - the dry-run unsets and token-source line.
   - `tests/test_substrate_lease.py`: the fixture writes env files; a deleted file is refused with no request sent; the lease call carries the env-file token; a 0644 file is refused; `not-holder` comes through a rewritten file.
   - `tests/test_substrate_tee.py`: with only A01's `SUBSTRATE_TOKEN` in the runner and A05's env file present, an A05 row is posted with A05's token; with no file and no override the row stays local, with one stderr note and never A01's token. The tee stays fail-open, as v1.1 decided [lesson mem_43bc8ddeb0244fc69758a24005e42f75].
   - `tests/test_install_omp.py`: the two full-install tests pass `--no-substrate`.
9. Docs:
   - agent-substrate: `docs/swarm-workspace.md` and a link from `swarm-correlation.md`.
   - agent-swarm: `docs/substrate-workspace.md`, plus `substrate-tee.md`, `substrate-leases.md`, README, AGENTS.md and CLAUDE.md.
