## Shared contract (U1 defines it; later units import it)

`packages/mcp-server/src/reconcile.ts`:
- `type Layer = "ledger" | "index" | "cache"`
- `type LeaseHold = { surface: string; session_id: string; epoch: number }`, or `null` for free.
- `interface Finding { comparison: "lease" | "memory" | "generation"; key: string; detail: string }`
- `interface Report { schema: "substrate.reconcile.report.v1"; generated_at: string; window_hours: number; counts: Record<string, number>; truncated: Record<string, boolean>; unchecked_memory_rows: number; findings: Finding[]; first: { lease: Finding | null; memory: Finding | null; generation: Finding | null }; clean: boolean }`
- `compareLeases(ledger: ReadonlyMap<string, LeaseHold>, index: ReadonlyMap<string, LeaseHold>): Finding[]`. Key is `graph_id/node_id`. Covers only the keys present on either side. Compares identity while held; does not compare expiry; both free is not drift.
- `compareMemory(index: ReadonlySet<string>, ledger: ReadonlySet<string>): Finding[]`. Both directions. Key is the entry id.
- `compareGenerations(genGraphIds: ReadonlySet<string>, indexGraphIds: ReadonlySet<string>): Finding[]`. Key is `gen:graph:<id>` for each orphan.
- `buildReport(input): Report`. Findings sorted by key. `first` is the first finding of each comparison. `clean` is true when there are no findings and no truncation.

## Wave B

### U2: readers, scan and run (`reconcile-read.ts`, `reconcile-read.test.ts`, `cache.ts`, `index-store.ts`, `reconcile-run.ts`)
Files: `packages/mcp-server/src/reconcile-read.ts`, `packages/mcp-server/src/reconcile-read.test.ts`, `packages/mcp-server/src/reconcile-run.ts`, `packages/mcp-server/src/cache.ts` (add only the scan and unlink methods), `packages/mcp-server/src/index-store.ts` (add only read-only reconcile methods).
Change:
- `readLedgerLeases(ledger, since)`: `queryEvents` over kinds `claim`, `warning`, `note`, filtered to payload actions `granted`, `reclaimed`, `stolen`, `released`, `forced`, `expired`. Keeps the latest transition per key. A release or expiry gives a free key.
- `readLedgerMemoryIds(ledger, since)`: audit events in the window with `payload.outcome === "accepted"` and a `payload.entry_id`.
- `readIndexLeases(index, keys)`: `graph_nodes` holds for the ledger keys, plus every node with `claimed_by` not null.
- `readIndexMemoryIds(index, since)`: `memory_entries` ids created in the window.
- `readIndexGraphIds(index)`: `graph_index` ids.
- `ReadThroughCache.scanKeys(match, limit)`: read-only SCAN with a cap, returns `{ keys, truncated }`. `ReadThroughCache.unlinkKeys(keys)`: UNLINK in batches, returns the count.
- `runReport(deps): Promise<Report>`: wires the readers into `buildReport`. Writes nothing.
Acceptance: fake ledger, fake index and fake cache tests. A recording fake proves `runReport` performs no write. A scan that hits the cap reports `truncated`.

## Wave C (after U2)

### U3: confirmed repair (`reconcile-repair.ts`, `reconcile-repair.test.ts`)
Files: `packages/mcp-server/src/reconcile-repair.ts`, `packages/mcp-server/src/reconcile-repair.test.ts`.
Change:
- `planFromReport(report, now): Plan` with schema `substrate.reconcile.plan.v1`. It lists one flush item per generation orphan, plus the prefix, and a `report_digest`.
- `digestOf(plan): string`: sha256 of the canonical plan items.
- `executePlan(plan, deps, { execute })`. Without `execute`, it returns what it would do. With `execute`, it checks the digest, re-runs `runReport`, refuses if the orphan condition no longer holds, flushes `substrate:v1` with `unlinkKeys`, and returns the result. The caller writes `<plan>.result.json`.
Acceptance: dry run writes nothing; digest mismatch refuses; a gone orphan refuses; execute flushes only the prefix; a second execute finds nothing to repair.
