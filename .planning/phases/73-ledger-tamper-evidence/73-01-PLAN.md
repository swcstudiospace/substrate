Context: `73-CONTEXT.md` (decisions D73-01 to D73-07). Branch `gsd/v18-p73-ledger-tamper`, worktree `/root/src/worktrees/as-gsd-v18-p73`, base origin/main `b1b42f92`.

Every task runs serially and edits only the files it names. Subagents edit only; the orchestrator runs all gates after each unit.

## U1 Memo v2 (packages/ledger)

Files: `packages/ledger/src/memo.ts`, `packages/ledger/src/merkle.ts` (read), and the existing memo test file under `packages/ledger`.

- Add `substrate:v2:` memo format carrying the hour root, count and `heads_root`. `formatMemo` writes v2 for new anchors. `parseMemo` accepts v1 and v2 and rejects any other prefix.
- Add `headRecordHash(record)` and `headsRoot(records)` (sorted by graph id, RFC 6962 Merkle root) using the existing hashing helpers.

Acceptance: a v1 memo parses unchanged; v2 round-trips; a malformed v2 (bad length, non-hex root, missing heads_root) is refused; `headsRoot` is independent of input order.

## U2 Head builder, leaves table and anchor writer (packages/mcp-server)

Files: `packages/mcp-server/src/anchor.ts`, `packages/mcp-server/src/greptime.ts`, and the anchor test file.

- `buildGraphHeads(events, periodStart)` groups an hour's events by graph and orders each graph's events by chain order (`inChainOrder` from `event.ts`). It returns records per D73-02.
- Add `graph_chain_leaves` DDL (`CREATE TABLE IF NOT EXISTS`) and `insertGraphLeaves`, written before the anchor row. Writes use the existing insert helper pattern.
- `anchorRow` emits a v2 memo once `heads_root` is computed. The v1 path stays for re-verification of old hours.

Acceptance: heads are deterministic for the same events; leaves are written before the anchor; a failed leaves write blocks the anchor write (no anchor without its leaves); v1 hours still verify.

## U3 Verifier and verdict (packages/mcp-server)

Files: `packages/mcp-server/src/event.ts`, `packages/mcp-server/src/service.ts` (`verifyGraph`, `hourReport`, `VerifyVerdict` only), and the event and service test files.

- Add `compareToAnchoredHead(events, leaves, anchoredHead)` implementing D73-03.
- `verifyGraph` sets `trusted` per D73-04 and fills `first_differing_event_id` or `first_missing_event_id`.
- Criterion 1 tests: save the head, then (a) edit a stored payload, (b) delete a middle event, (c) truncate the last events, (d) rewrite the whole chain with recalculated `hash` and `prev`. Each reports the expected id. Add an unanchored case and a v1-only case that report `trusted: false`. Add a case where the stored leaves are edited but the on-chain `heads_root` is unchanged, reporting `stored-leaves-mismatch`.

Acceptance: every named mutation yields the expected id; no recomputed head is ever reported as trusted; existing `verifyGraph` callers keep their current fields.
