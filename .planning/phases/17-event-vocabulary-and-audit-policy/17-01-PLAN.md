## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reviewer→table | A later PR edits `EVENT_SOURCES` or the doc to smuggle in a new kind or surface |
| sample→ledger | Sample payloads set the precedent later mappers copy into the append-only ledger |
| token→surface | A caller presents a `substrate` token but names another surface on `/events` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-01a | Tampering | EVENT_KINDS / SURFACES | high | mitigate | Ordered-literal lock test in plain `bun test` (12 kinds, 27 surfaces with `substrate` last) plus the plan 17-03 git baseline diff; both must be edited together with the doc to land a widening |
| T-17-01b | Information disclosure | sample payloads | medium | mitigate | No-content-key test rejects text/content/body/bytes/image/png keys; hashes are 64-hex literals; deep-equal against `normalizeEvent` output proves the redactor leaves them intact |
| T-17-01c | Tampering | doc-vs-table drift | low | mitigate | Marked-table parse test asserts identical id sets and per-row kind/action equality |
| T-17-01d | Spoofing | substrate token binding | medium | mitigate | `attributedSurface` binds a `substrate` caller to its own surface like a swarm token; binding tests prove own-surface emit stores and cross-surface emit is refused on `/events` and via `attributedSurface` |
