<objective>
Make graph_release and graph_complete mirror the ultrathink-sync state table on Linear and route
Done through the connector's DoD gate (SC-2), with the two new event kinds (D-08) and an ownership
check so only the claiming session can move a claimed issue.

D-06 mechanism (derived in 02-03, rated costly): substrate moves the issue to In Review itself,
then forwards the caller's DoD evidence to `POST /v1/complete-issue`; the connector alone decides
and alone moves the issue to Done. Substrate holds no copy of the rule.

Ownership (research Open Question 3, security note): substrate-mcp is anonymous, and after this
plan release/complete can move Linear issues. Requiring the caller's surface to equal
`claimed_by` and its session_id to equal `claim_session` means one agent cannot release or close
another's work by accident or through an injected instruction. This changes the two tools'
input schemas (session_id becomes required) — reversible: no caller of graph_release or
graph_complete exists anywhere on the host (grep of claude-ultrathink, hermes-plugin, mcp,
omp-ultrathink and the plugin cache during planning).

Notion writes for release and complete land in 02-06 through the same Mirror methods.

Purpose: SC-2 (Linear half), D-05, D-06, D-08.
Output: release/complete wiring, DodGate client, new kinds, tool schemas, live smoke on the
tracer issue from 02-01 (which ends Done through the gate).
</objective>
