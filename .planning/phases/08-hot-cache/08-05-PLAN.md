## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RAGFlow / Agentmemory results → Dragonfly | Third-party and recalled text is stored off-box for up to 1 h / 60 s. |
| anonymous callers and VM guests → docs_search / context_search | Open read tools; a shared cache entry serves any caller. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-05-01 | Information Disclosure | Unredacted text written to Dragonfly | high | mitigate | Values are the already-redacted objects the tools return; the redact() write guard; live raw-value check (redaction-stable, 0 token shapes). |
| T-08-05-02 | Information Disclosure | A cached answer served to a caller who should not see it | low | accept | Both tools are open by design (05-05 D-19, Phase 7 D-06) with no per-caller filtering; the caller's surface only attributes the event, so sharing adds no exposure. |
| T-08-05-03 | Tampering | Stale docs after an ingest, or stale recall | medium | accept | Owner-accepted TTLs (D-06): 1 h docs, 60 s recall; no invalidation hook is in scope. |
| T-08-05-04 | Repudiation | Cache hits hiding tool usage from the ledger | medium | mitigate | tool.call is emitted outside the wrap on every call (tested; live count = 5). |
| T-08-05-05 | Denial of Service | Caching a fail-open empty for 60 s after an Agentmemory blip | medium | mitigate | `reason`-bearing results are never written (tested); errors are never written. |
| T-08-05-06 | Tampering | Key collisions across scopes | low | mitigate | sha256 over canonical JSON of the normalized query and the full scope; docs/ctx prefixes (tested). |
| T-08-05-SC | Tampering | Package installs | low | mitigate | None (sha256 from Bun/node built-ins); verify fails on any manifest or lockfile change. |
