## Task 1 — `SessionRegistry` view (`session-registry.ts` + `IndexStore.sessionRegistry()`)

New file `packages/mcp-server/src/session-registry.ts` (planning-adjacent pure view + port, like `worktree-registry.ts`):

- Row types mirroring the three tables: `RegistryGraphNode` (`graph_id, node_id, claimed_by: Surface, claim_session, claimed_at, lease_expires_at, lease_heartbeat_at, lease_epoch`; schema `index-store.ts:393`), `RegistryLiveBinding` (`session_id, owner_surface, repo_id, expires_at, closed_at`; `index-store.ts:902`), `RegistryWorktree` (`host, path, repo, branch, session_id, graph_id, last_seen_at, files, files_truncated`; `index-store.ts:756` + `changed_files` at `index-store.ts:880`).
- Pure `buildSessionRegistry(rows, nowMs, { worktreeTtlMs })`: a session is live when any holds — unclosed **and** unexpired `live_session_bindings` row (`closed_at` null, `expires_at > now`), a held lease (`leaseState(snapshot, now) === "held"`, `lease.ts:120`), or a fresh worktree (`last_seen_at` within `DEFAULT_WORKTREE_REGISTRY_TTL_S`, `worktree-registry.ts:33`, injectable for tests). Entries are the union per session of attributed worktrees (`worktree.session_id === session_id`, carries `files` from `changed_files` then `.files` fallback) and held nodes (`claim_session === session_id`, attached to the matching `graph_id` worktree entry when present, else a `worktree_path: null` entry); a live binding with neither still yields one null-worktree entry. Per-entry `{ session_id, surface, repo, worktree_path, graph_id, node_id, lease_state, epoch, expires_at, files, files_truncated }`, **never** `lease_id` (the secrecy rule: `lease.ts:433` — readers never see the fencing token). Sorted deterministically by `(session_id, worktree_path ?? "", graph_id ?? "", node_id ?? "")`.
- Pure `detectSessionConflicts(entries)`: every `(worktree_path, file)` carried by ≥2 **distinct** `session_id`s → `{ worktree_path, file, session_ids }` sorted by `(worktree_path, file)`, `session_ids` sorted. Empty `files` lists never conflict.
- `SessionRegistry` class holding `lastKnown`: `async current(store, now)` returns `{ entries, conflicts, as_of, degraded }` — a store failure returns last-known (empty on a cold start) with `degraded: true`, **never throws** (fabric style per CONTEXT).
- Operator helpers reusing the lease algebra (no new auth layer): `registryTake(snapshot, holder, caller)` wraps `decideClaim` (`lease.ts:218`; stranger-surface renewal is `denied("not-holder")` via `isStranger`, `lease.ts:247`); `registryRelease(snapshot, { lease_id, force }, caller)` wraps `decideRelease` (`lease.ts:388`; holder check `lease.ts:401`, no-lease-id path refuses `lease-id-required`, `lease.ts:413`).
- `SessionRegistryStore` port (`snapshot(): Promise<RegistryRows>`) + `PgSessionRegistry(sql, run)` (bounded reads: claimed nodes ≤1000 (nodes with `claimed_by`/`claim_session` set, ordered `(graph_id, node_id)`), open bindings ≤1000 (`closed_at is null`), worktrees ≤500 newest-first — mirroring `PgWorktreeRegistry.list`/`candidates`, `worktree-registry.ts:388/408`) + `MemorySessionRegistry` fake (the `MemoryWorktreeRegistry` pattern, `worktree-registry-fake.ts:18`).
- `index-store.ts`: `sessionRegistry(): SessionRegistryStore` beside `worktreeRegistry()` (`index-store.ts:1336`), constructed over `this.sql` with `(op, fn) => this.plane(op, fn)`.

Acceptance: `session-registry.test.ts` (fakes only, fixed `now`) — join of binding+lease+worktree for one session; expired binding / free-or-lapsed lease / stale worktree each excluded; cold-start failure is `{ entries: [], degraded: true }` and a post-success failure returns last-known still `degraded: true`; conflict grouping/sorting incl. same-session-no-conflict; `registryTake` stranger denial and `registryRelease` lease-id-required / holder-ok cases.

## Task 2 — `session_registry` MCP tool + `SubstrateService.sessionRegistrySnapshot`

- `service.ts`: `sessionRegistrySnapshot(query, callerSurface)` mirroring `listWorktrees` (`service.ts:5540`): a named `repo` is gated by `authorizeRepo` and refused via `repoRefusal`; `grantedRepos` scopes the returned entries (empty grant → empty snapshot); no index configured → degraded empty snapshot (never 503, CONTEXT degrade rule); store failure → last-known via the cached `SessionRegistry` (build once, lazy, beside `worktreeFromIndex`, `service.ts:1611`); entry filter by `repo` is case-insensitive (`lower(repo)`), conflicts recomputed over the filtered entries via `detectSessionConflicts`.
