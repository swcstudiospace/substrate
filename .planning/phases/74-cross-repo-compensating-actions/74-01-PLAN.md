Decisions D74-01 to D74-12 in `74-CONTEXT.md`.

## Criteria

| # | Criterion (ROADMAP) | Tasks | Evidence |
|---|---|---|---|
| C1 | An actual operation across at least two registered repositories persists operation and step state before effects, with stable dedupe keys and idempotent per-step retry. | T1, T2, T3 | tests: "a branch is cut in every repository and the steps are recorded applied", "a retry with the same key runs no effect", "a retry with the same key after a crash between create and record adopts the ref without a second create", "a key reused for a different request is refused" |
