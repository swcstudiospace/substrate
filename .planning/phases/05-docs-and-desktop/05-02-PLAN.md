<interfaces>
RAGFlow HTTP API (research Q1, pinned at v0.26.4 and v0.27.2; `Authorization: Bearer <RAGFLOW_API_KEY>` except the first three):
- `GET /api/v1/system/version` → `{code:0, data:"v…"}`; `GET /api/v1/system/config` → `data.registerEnabled` 0|1; `GET /api/v1/system/healthz` → HTTP 200 `{status:"ok", …}`.
- `GET /api/v1/datasets?page=N&page_size=100` → `data:[{id, name, embedding_model, …}]` (match names on the client; `?name=` errors when absent, code 102).
- `POST /api/v1/datasets` `{name, chunk_method:"naive", permission:"me", parser_config:{chunk_token_num:320, delimiter:"\n", auto_keywords:0, auto_questions:0, raptor:{use_raptor:false}, graphrag:{use_graphrag:false}}}` — no embedding_model, no auto_metadata_config (D-05) → `data.id`, `data.embedding_model`.
- `DELETE /api/v1/datasets` `{ids:[id]}`.
- `POST /api/v1/datasets/{id}/documents` multipart, repeated `file` → `data:[{id, name, run}]`; a duplicate name becomes `name(1).md`; partial success is `code:500` with `data`.
- `PATCH /api/v1/datasets/{id}/documents/{doc}` `{meta_fields:{url, title, source, content_hash}}` (the v0.26.4 docs say PUT; code says PATCH).
- `POST /api/v1/datasets/{id}/chunks` `{document_ids:[≤100]}`; poll `GET …/documents?page_size=100&run=UNSTART&run=RUNNING` until total 0; `run=FAIL` lists failures.
- `DELETE /api/v1/datasets/{id}/documents` `{ids:[1..100]}` (empty is refused).
- `POST /api/v1/retrieval` `{question, dataset_ids:[id], page:1, page_size:≤10, similarity_threshold:0.2, vector_similarity_weight:0.3, highlight:false, reference_metadata:{include:true, fields:["url","title","source"]}, metadata_condition?:{logic:"and", conditions:[{name:"source", comparison_operator:"=", value}]}}` → `data.chunks[{content, document_id, document_keyword, similarity, document_metadata?}]`. Never sent: keyword, use_kg, toc_enhance, cross_languages, meta_data_filter, rerank_id, top_k, knn_top_k.
- Errors: unknown key → HTTP 401; most failures HTTP 200 with `code ≠ 0`.
