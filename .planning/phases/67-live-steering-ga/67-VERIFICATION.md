## Residual risks

- **Criterion 3:** the combined brief is not proved to stay inside the compact byte cap with live sections present.
- **The hint after a restart.** A directive acknowledged before a restart is read back from `planning_steering_audit`, which stores no transition result, so it carries `checkpoint_hint: null` and the hook writes no checkpoint for it. Pinned by `steering-wiring.test.ts` `"the route still lists a directive that was acknowledged before the restart, with no checkpoint hint (the audit holds no transition result)"`; documented in [live-steering.md](../../../docs/live-steering.md) ("Limits").
- **Durability scope.** Without `SUBSTRATE_PLANNING_STEERING_AUDIT_TABLE` the inbox is memory-only (a restart forgets queued directives) even with the sessions table on; the sessions table covers session state only.
- **No route-level audit-refusal test.** The audit class of each route is pinned by the policy tests; no test makes the audit sink refuse a REST steering call and checks the 503.
- **Held connections.** A long poll counts as one admission for as long as it waits; the waiter bounds (4 per session, 256 overall) answer 429 past them.
- **A stale session stays listed** in the digest until its age says so; there is no liveness expiry beyond the cap and the boot TTL.
- The tests run against fake servers and fake stores; delivery to a real session was never exercised (also stated in [live-steering.md](../../../docs/live-steering.md)).

### Hook installer (repository code, tested with fakes)

The gap was that the printed Claude Code `Stop` hook had no installer. `substrate session hook-install claude-code --settings PATH [--write]` (`packages/cli/src/session/hook-install.ts`, dispatch in `command.ts`) merges that hook into a settings file. It is dry run by default and prints the hook block, never the file, which can hold an `env` block with credentials. With `--write` it copies the previous file to `PATH.substrate-backup`, writes a temporary file and renames it, keeps the file's permission bits (a new file is `0600`), and refuses a symbolic link (a rename would replace it), a malformed or wrong-shaped file, a non-regular file and a file over 1 MiB. It is idempotent. Tests: `hook-install.test.ts` (22 tests, scratch directories only). Only `claude-code` is accepted: ADR 0007 maps the `Stop` event to it. `steering`, `baseline`, `context` and `git-post-commit` need host values or an event the operator chooses, so they stay printed text.
