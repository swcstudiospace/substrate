## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine→child git/gh | argv plus allowlisted env cross into subprocesses |
| engine→library repo | push plus gh pr create spend the owner credential |
| config→engine | env-provided repo, remote and gh binary steer every proposal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01 | Tampering | skills/propose.ts argv | high | mitigate | No force flag, colon refspec or search query in any builder, pinned by tests; fresh branch per proposal |
| T-21-02 | Information disclosure | skill content to PR | high | mitigate | validateProposal runs scanSkillFiles from Phase 18 redact.ts; any finding throws ProposeRefused before git |
| T-21-03 | Information disclosure | child env | high | mitigate | createExecFileRunner passes the four base keys PATH, HOME, GIT_TERMINAL_PROMPT=0, GH_PROMPT_DISABLED=1 plus seven controlled fixed Git values (GIT_CONFIG_GLOBAL/SYSTEM=/dev/null, two-entry gh credential-helper selection); store URLs, surface tokens and the handoff key never reach children (user-selected Keep current Git isolation 2026-10-11) |
| T-21-04 | Elevation of privilege | library config | medium | mitigate | Non-default repo or remote requires file:// plus absolute non-default gh; origin and PR-URL slug checks use the configured slug |
| T-21-SC | Tampering | dependencies | low | accept | No package is installed by this plan; rationale: Bun, git and gh only |
