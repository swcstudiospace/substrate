<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| projector env → bundle files → Muse cache | Operator env flows into world-readable cache dirs; a token value there leaks |
| generated hook → POST /events | Hook runs inside Muse's runner with a scrubbed env; wrong config URL posts to production |
| redact.ts bytes → bundle copy | A stale or hand-edited copy silently changes what the hook redacts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-13 | Information disclosure | token value in bundle or cache | high | mitigate | substrate.json holds a path never the value; projector refuses env-derived literals; SENTINEL test proves absence (D19-18) |
| T-19-14 | Tampering | hook posting to production | high | mitigate | Config URL asserted equal to the harness URL before any proof hook run; missing token file posts anonymously to the configured URL only, never a fallback (Pitfall 1) |
| T-19-15 | Information disclosure | redactor drift between repo and bundle | medium | mitigate | Byte-copy with source-commit plus sha256 header; --check compares installed sha256; research-verified lock regexes see no violation |
| T-19-16 | Elevation of privilege | user-scope install confusion | medium | mitigate | Proof installs into scratch HOME with XDG unset and no-auto-update; operator list cache paths asserted unchanged before and after (D19-20) |
</threat_model>
